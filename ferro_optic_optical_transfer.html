DECIMEN X FERROFY // ARCHITECTURE INSPECTOR

光學噴泉碼四大核心運作機制 (Interactive Spec)

01 // LT FOUNTAIN CODES
無速率噴泉碼 (XOR 水滴)

螢幕到鏡頭是單向通道。發送端將檔案切為 K 塊並隨機 XOR 混成無限「水滴」。接收端不論順序、不怕反光漏掃，只要接滿約 1.15×K 滴水即可透過圖論剝離演算法 100% 還原。

02 // 22-BYTE WIRE HEADER
無需握手的自描述幀

每個 QR Code 均攜帶 22 Bytes 表頭（Session ID、序號 Seq、檔案總長度、區塊大小）。接收端可在任意時刻舉起手機對準螢幕，中途加入也能無縫重組。

03 // SPLITMIX32 PRNG
雙端偽隨機數配方同步

為了節省 QR 容量，水滴內不記錄「混合了哪幾個區塊」，而是由收發兩端共用確定性 SplitMix32 演算法，僅憑 Frame Seq 序號即可同步推算出完全一致的 XOR 索引組合。

04 // DCF2 & SHA-256
容器封裝與雜湊校驗

自動將檔名、MIME 類型與二進位負載封裝為 DCF2 結構，並在接收端拼湊完成後執行完整 SHA-256 與 CRC32 校驗，確保每一個位元組零誤差。
